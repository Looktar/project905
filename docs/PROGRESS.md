## 2026-11-01 · 手机试玩反馈修复（v0.1 已合并上线）
总决策手机试玩反馈了两个问题，都已修复：
- **拖摇杆时整个网页跟着跑**：iPhone Safari 和微信等内置浏览器不完全遵守 `touch-action:none`，单指拖动会拖动或回弹整页，而之前只拦了双指。
  - 现在除了设置面板这种可滚动区域，所有触摸滑动都被拦住，html/body 也固定住。
  - 冒烟测试新增检查：拖摇杆时触摸滑动必须被拦。
- **NPC 走路飘移、闪现**：
  - **飘移**：路人跟随的目标点在路口转弯时会跳几米，旧代码用指数插值追过去，经常超过 6 米/秒。现在按步行速度走过去，目标点会等人。60 秒模拟中滑行帧由约 900 降到 0–2。
  - **闪现**：新路人和新车以前在 40–95 米处生成，常常就在屏幕里。现在只在屏幕外生成。90 秒跑动 / 开车测试中，屏幕内凭空出现分别由 4 / 7 次降到 0 / 0。
  - 顺带：过马路被挡住 3 秒会放弃并重新找人行道；逃跑后的路人会回到人行道；碰到水边原地掉头，不再弹跳。
- 单元测试 78 个，新增两条：NPC 走路不超过快走速度；跑动 / 开车时没有东西在屏幕里冒出来。
