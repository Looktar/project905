## 2. mrdoob/slop-newyork（总决策：“再去研究一下这个”）
- **是什么**：three.js 作者 mrdoob 2026-10-20 开源的曼哈顿模拟（MIT 许可），[在线试玩](https://mrdoob.github.io/slop-newyork/)。步行、开车、骑车、坐直升机逛纽约。用 WebGPURenderer + TSL 着色器。约 460 star。
- **数据**：真实 1:1 比例（我们是 0.4 倍）。NYC Open Data 的建筑轮廓**和楼高**、行道树位置、地铁出入口，加 OSM。生成脚本在 `tools/`，数据压缩成 `.bin.gz`。和我们用 York Region 数据的做法一样。
- **做得细的地方**：店面橱窗和招牌、楼门口、消防梯、路面裂缝补丁、人行道砖缝、行人走路 IK、合成音效带声学（混响/遮挡）、黄金时刻/蓝调时刻光照、雷达小地图、全城大地图（可搜索街道和地标、传送、GPS 导航）、多机位（无人机、地标机位）、隐藏 HUD。
- **传播**：作者说“Fork it, remix it”，4 天出现 35+ 个城市改版，一周 41 个，社区整理成 [Awesome Slop Cities](https://github.com/zz85/slop-cities)（已有多伦多、伦敦、柏林、新加坡等，带世界地图）。
- **和我们比**：它追求写实和细节，需要 WebGPU，偏电脑；我们是卡通玩具城、WebGL2、手机优先、有玩法（打人、警察、任务、放火）。它几乎没有玩法目标，我们有。
- **值得吸收**（按性价比）：
  1. **全城大地图 + 搜索 + 传送 / 导航**：点小地图打开，搜“Pacific Mall”直接导航或传送。我们已有路网 A* 和任务路线，做起来便宜。
  2. **拍照模式**：隐藏 HUD + 地标机位，适合截图分享（配合“分享链接”）。
  3. **时间段光照**（黄金时刻 / 傍晚）：只改光照颜色和雾色，成本低，画面差别大。
  4. **自行车**：新载具，步行和开车之间。
  5. **登记到 Awesome Slop Cities**：我们不是它的 fork，但列表收“同类浏览器城市模拟”。这是对外发布，要总决策同意。
- 不吸收：WebGPU（iPhone 支持还不稳）、1:1 比例（D-64 已讨论）、写实材质（和卡通画风冲突）。
