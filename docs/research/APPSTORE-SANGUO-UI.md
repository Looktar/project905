# App Store《三国志》单机手游：界面能学什么（2026-11-05）

> 总决策要求：“加拿大地区的 Apple Store 有一款手机游戏叫《三国志》单机手游，去看一看有什么可以吸收的，尤其是它的 UI 设计和界面。”
> 看的是《三国志 - 三国志单机手游》（https://apps.apple.com/ca/app/id6443516223 ）的商店介绍和截图。没有下载游戏，没有使用它的任何图片、文字或数值；下面只记设计思路，我们全部自己用代码画（D-84）。

## 它的界面特点
| 特点 | 它怎么做 | 我们的情况 | 结论 |
|---|---|---|---|
| 竖长武将卡 | 大立绘、国别竖签、星级、稀有度角标，名字压在卡片底部 | 只有圆形头像 | **学**：代码画的竖卡（大字头像 + 国别色） |
| 武将列表页 | 底部导航进“武将”，左侧按国别分页，右侧卡片网格，点开看详情 | 武将只在城池面板里 | **学**：顶栏“将”按钮 + 分类卡片墙 + 详情页 |
| 战斗画面 | 左右对阵，双方武将卡上有兵力条，打一回合掉一截 | 地图上交锋动画 + 一句结果 | **学**：用引擎真实的每回合兵力播放 |
| 地图信息量 | 大地图上只有城名，细节点进去才看 | 缩小时数字和关名挤在一起 | **学**：缩小时只留城名 |
| 日期 + 天气 | 顶栏年月旁边有天气图标 | 只有年月 | **学**：天气跟季节规则一致（冬天下雪） |
| 底部圆形单字按钮 | 城 / 将 / 军 / 设 | 顶栏文字按钮 | **部分学**：手机上“报 / ≡”改圆形单字 |
| 体力、商城、签到、抽卡付费 | 典型手游运营 | 不需要 | **不学**（给朋友玩，不变现） |
