# 决策记录

已确认的立项决策见 `docs/kickoff-prompt.md`。以下为实现过程中的补充决策。

- **D-01（2026-10-31）v0 不用 Three.js/Vite/TS**：制作环境无法访问 npm，v0 用原生 WebGL2 + ES Modules 完成，零依赖、零构建，GitHub Pages 直接托管。下一阶段由 Claude Code 评估：继续原生（体积小、已可玩）还是迁移到规格中的 Three.js + Vite + TS。迁移属于大重构，需先与总决策确认。
- **D-02 地图西边多留约 170 米**：为把万锦市政厅包进来（它在 Warden 以西）。
- **D-03 GitHub Pages 用“从 main 分支根目录部署”**：无构建步骤，不需要 Actions；`.nojekyll` 关闭 Jekyll。若将来引入构建再改为 Actions。
- **D-04 人物用程序化分段小人**（大头、身体、四肢、帽子），不用骨骼蒙皮；车也是程序化几何体。
- **D-05 树用二十面体树冠**（低多边形风格 + 省顶点）。
- **D-06 开车撞普通车不算犯事**；撞警车、撞人、打人、抢车算犯事。
- **D-07 主角脱离战斗 5 秒后自动回血**（没有补给道具）。
- **D-08（2026-10-31）不迁移 Three.js，继续原生 WebGL2；只在开发阶段引入工具**：云端环境现在能连 npm，但迁移要重写渲染层（约 1–2 个工作周期），玩家感受不到区别，还会多 ~600KB 和构建步骤；当前 37 draw call、JS 156KB，性能有余量。Kenney 站点在云端被拦（403），GLB 素材仍需在电脑上下载，届时原生写最小 GLB 加载器即可。折中：`package.json` 只放开发依赖（ESLint、Vitest、Playwright），游戏本身仍零构建、GitHub Pages 直接托管（D-03 不变）。以后若要大量 GLB 模型、复杂后期，或代码超过约 8000 行，再重新评估。
- **D-09 不用 Prettier**：现有代码是紧凑写法，全量格式化会产生巨大 diff、淹没真实改动；用 ESLint 只查真问题（未定义变量、未使用变量等）。
- **D-10 v0.1 打磨里程碑并行开发**：项目经理（Claude）拆成 4 个工作包——工程底座（测试/CI）、红绿灯与车型、地标与街道道具、遮挡半透明与设置页——由子代理在独立 worktree 并行开发，项目经理负责集成、验收截图和 PR。
