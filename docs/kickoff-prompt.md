## 1. 项目概述
- **代号**：Project 905（正式名以后定）。
- **一句话**：网页加手机浏览器都能玩的 3D 卡通“玩具城”开放世界小游戏，地图基于真实万锦。玩家在大地图上溜达、打路人、抢车开，街上有巡逻警察。
- **核心乐趣**：在“熟人一眼能认出来”的万锦街道上溜达探索，搞点小破坏，看路人的各种搞笑反应。
- **发布**：GitHub Pages，推到 `main` 自动部署，链接发给朋友就能玩。

## 2. 玩法规格（所有数值放 `src/config/`，方便调参）

### 2.1 主角
- **动作**：走、跑、出拳、上车、下车。
- **出生点**：Hwy 7 × Kennedy Rd 路口东南角的人行道。
- **生命值**：100。脱离战斗 5 秒后缓慢回血（没有补给道具）。
- **被打倒**：晕 3 秒，原地爬起，恢复 50% 生命值。之后 3 秒无敌，正在打他的路人放弃攻击，避免被连续揍倒。**没有任何惩罚**。
- **被车撞**：和路人一样被撞飞倒地。

### 2.2 路人
- **行为**：沿人行道随机走动，偶尔过马路。
- **随机属性**：每个路人生成时随机分配
  - 生命值 30–120
  - 力量（攻击倍率 0.5–2.0）
  - 性格（默认权重）：胆小 50%，普通 35%，暴躁 13%，隐藏高手 2%（会反过来把主角揍趴下）
- **挨打反应**：按性格随机逃跑、倒地或还手。
- **生命值归零**：倒地，头上冒星星，8–12 秒后爬起来逃跑。
- **被车撞**：卡通式撞飞后倒地。**不会死亡**。
- **围观反应**：约 15 米内看到打架或撞人的路人，按性格概率逃跑或尖叫。

### 2.3 车辆
- **类型**：轿车、SUV、出租车、面包车、警车（主角也能抢）。
- **公交车**：Viva 蓝色公交车在 Hwy 7 中央快速公交道上跑，是实体，会撞倒挡路的人。v0.1 不能上公交车。
- **抢车**：靠近车辆按“上车”。空车直接上；有司机就把他拽出来，司机随机逃跑或还手。
- **驾驶**：街机手感，有加速、刹车、倒车、手刹漂移。开得越快镜头拉得越远。
- **损坏**：车有耐久，撞多了冒烟熄火，主角要下车。**不爆炸**。
- **撞普通车**：不算犯事。这是休闲游戏，开车乱撞本身就是乐趣。

### 2.4 交通
- 沿车道靠右行驶。
- 主干道路口有红绿灯，车会等灯。
- 前方被挡住时减速、按喇叭。

### 2.5 警察（简单版，不做星级）
- **巡逻**：街上随机有步行巡逻警察和巡逻警车。
- **算犯事的行为**：
  - 打人（包括打警察）
  - 抢车
  - 开车撞人
  - 开车撞警车
- **目击**：警察约 25 米内、视线没被建筑挡住时看到犯事，开始追捕。约 60 米内的其他警察一起来。
- **甩掉**：脱离所有警察视线约 10 秒，他们放弃追捕，回去巡逻。
- **怎么追**：
  - 主角步行时，步行警察跑过来追；警车开到附近，警察下车追。
  - 主角开车时，警车追，并尝试别车。
- **被抓的条件**：
  - 步行时：被警察抓住约 1.5 秒，或被警察打倒。
  - 开车时：车速接近 0，且被警察或警车贴身围住约 2 秒；或者车坏熄火后被警察贴身。
- **被抓之后**：约 2 秒卡通“被抓了！”动画。然后主角在 150–300 米外重新出现，要远离所有追捕中的警察，不在水里或铁轨上，优先选已加载的区块。追捕清零，**没有任何惩罚**。
- **打警察**：可以打，但他们比路人耐打（生命值约 150），出拳更重。

### 2.6 不做的东西
- **永远不做**：枪械。
- **v0.1 不做**：
  - 金钱和分数（不是核心，暂不做）
  - 通缉星级（暂不做）
  - 补给道具
  - 任务剧情
  - 进入建筑
  - 联网多人

## 3. 地图规格

### 3.1 范围
- 万锦，以 Hwy 7 为主轴：东西从 Warden Ave 到 McCowan Rd，南北从 Steeles Ave 到 16th Ave。
- 用这四条路围成的多边形外扩约 200 米作为数据范围。
- 以后可能扩到 Woodbine（First Markham Place）和世嘉堡，记进 BACKLOG。

### 3.2 数据来源和获取
- 数据来自 OpenStreetMap，用 Overpass API 下载。
- **分批查询并设置超时**：道路、水体、铁路、土地用途、商业和地标建筑、带 `brand` 标签的店铺。
- **不下载住宅建筑轮廓**：住宅区是程序化摆房子，用不上。
- 原始数据**只下载一次**，gzip 压缩后提交到 `data/raw/`。之后构建不再联网。
- 游戏的标题页和设置页署名“地图数据 © OpenStreetMap contributors”。

### 3.3 坐标与方向
- **投影**：先投影成本地米制坐标。
- **转正**：万锦主干路网相对正北有一个偏角（大约十几度，具体从数据里量）。把整张地图旋转到主干路网横平竖直，即“地图北”。游戏里的东南西北、镜头方位、小地图朝上方向都以地图北为准。

### 3.4 比例与还原方式
- **压缩比例**：保留真实路网拓扑，坐标整体压缩到 **40%**（可配置）。道路宽度按游戏尺度设定，不随之压缩。
- **道路取舍**：
  - 保留：次干道及以上全部道路（Hwy 7、Kennedy、Warden、McCowan、Steeles、14th Ave、16th Ave、Main St Unionville、Enterprise Blvd 等），以及能连成环、有代表性的小区主路。
  - 舍弃：服务道路、步道、停车场内部道路。
  - 规则：任何街区压缩后最小进深不低于 20 米，低于就合并或删路。
- **住宅区**：不照搬真实房屋，在街区里程序化摆放卡通房子、树、栅栏。
- **地标和商业建筑**：轮廓按 40% 缩放后再乘一个可配置的放大系数，保证好认，但不能超出所在街区。
- **名称**：路名用真实名称，店名和品牌一律用谐音恶搞名。

### 3.5 道路怎么做
真实路网有斜路、弯路和各种形状的路口，套不上 Kenney 的 90° 方格路块。所以：
- 路面、路口、车道线、斑马线、人行道、快速公交道，全部由地图管线按道路几何**程序化生成网格**。
- Kenney 素材只用来做路灯、红绿灯、房子、车、树这些物件。

这是 M0b 和 M1a 技术难度最大的部分。

- **核对**：M0b 结束时把地标位置截图给我核对。
- **屋顶大道具**：是认出地标的关键，用几何体自己建模。

## 4. 美术规格
- **验收基准**：`docs/concept.jpg`。
- **风格**：3D 低多边形卡通“玩具城 / 微缩沙盘”。
  - 颜色鲜艳饱和
  - Q 版圆润大头小人
  - 柔和的方向光阴影
  - 街上热闹：红绿灯、路灯、消防栓、井盖、斑马线、树
  - 地标屋顶有夸张的大道具
- **镜头**：
  - 固定角度，带透视。
  - 垂直视场角约 30°，俯角约 45°。
  - 水平方位从地图东南方向看过去（相对地图北约 30°），能同时看到建筑的两个面。
  - **不旋转**。
  - 电脑端可以开“微缩模型”景深效果，手机端默认关闭。
- **遮挡**：楼挡在镜头和主角之间时，这栋楼变半透明，同时主角显示描边轮廓。
- **素材**：
  - Kenney CC0 素材：City Kit（Suburban / Commercial，只用建筑和道具）、Car Kit（含警车、出租车），颜色统一调亮。
  - 人物：用程序化的分段 Q 版小人（大头、身体、四肢分开建模）加代码驱动的动画，不用骨骼蒙皮，风格贴近概念图，也更省性能。Kenney Mini Characters 可以参考。
  - 所有素材在 `public/assets/CREDITS.md` 里登记来源和许可。

## 5. 界面、操作、声音

### 5.1 标题页
点击“开始游戏”进入，同时完成三件事：
- 解锁手机浏览器的声音（手机必须用户点一下才能出声）
- 显示 OpenStreetMap 署名
- 提供语言切换和操作说明

### 5.2 步行操作
- 电脑：WASD 或方向键移动，Shift 跑，空格出拳，F 上下车。
- 手机：左下角虚拟摇杆，右下角三个圆按钮“拳 / 上车 / 跑”。
- 移动方向相对屏幕：摇杆往上推就往屏幕上方走。

### 5.3 开车操作
- **电脑**：W 油门，S 刹车（停稳后继续按就倒车），A/D 转向（相对车身），空格手刹漂移，F 下车，H 喇叭。
- **手机**：
  - 摇杆往哪推，车就自动转向并开往屏幕上的那个方向，推得越远越快。
  - 往车头反方向推，先刹车，停稳后倒车。
  - 三个按钮在车上变成“漂移 / 下车 / 喇叭”。

### 5.4 手机适配：强制横屏（总决策要求，必须实现）
**iOS 上的做法**：iOS Safari 不允许网页锁定屏幕方向，所以用“画面旋转”实现强制横屏。
- 当浏览器处于竖屏状态（包括 iPhone 开着竖屏锁定的情况），把整个游戏根容器旋转 90° 并互换宽高。画面始终按横屏渲染，玩家把手机横过来拿就能正常玩。
- 默认顺时针旋转，与 iPhone 横屏刘海在左一致，旋转方向可配置。
- 用 `matchMedia('(orientation: portrait)')` 和 resize 事件监听方向变化，自动在“旋转模式”和“原生横屏”之间切换，切换时不重新加载游戏。

**输入坐标转换**：
- 所有触摸坐标统一经过一个坐标转换层，换算到游戏横屏坐标系。摇杆方向、按钮点击、UI 布局都基于转换后的坐标。
- 必须写单元测试覆盖四种情况：竖屏旋转模式、原生横屏，各自的左右两个方向。

**安卓上的做法**：点“开始游戏”后请求全屏，并调用 `screen.orientation.lock('landscape')`。成功就走原生横屏；失败就退回旋转方案。

**其他要求**：
- 安全区（刘海、底部横条）在旋转模式下也要正确换算，按钮不被遮挡。
- 禁止双指缩放、双击放大、下拉刷新、长按菜单；页面高度用 `100dvh`。

## 6. 技术方案

### 6.1 技术栈与架构
- 技术栈：TypeScript（strict）+ Vite + **Three.js**，npm 管理依赖，ESLint + Prettier 做代码检查。
- 架构：**玩法逻辑在 2D 平面上计算**（移动、碰撞、AI、寻路），**渲染用 3D**。
- 物理：Rapier 2D（`@dimforge/rapier2d-compat`）。
  - 先异步初始化 WASM，再进入游戏。
  - 固定物理步长 1/60 秒。
  - 建筑和水体是静态碰撞体，人和车是动态体。

### 6.2 地图管线
放在 `tools/map-pipeline/`，用 Node + TypeScript，依赖 osmtogeojson、@turf/turf、proj4。
- `npm run map:fetch`：Overpass → `data/raw/`（gzip）。
- `npm run map:build` 依次做：
  1. 投影、转正、压缩坐标
  2. 简化几何，按第 3.4 节取舍道路
  3. 按 highway 标签分级，确定路宽和车道数
  4. 生成道路网格
  5. 生成车道路网图（车流和警车用）和人行道路网图（路人用）
  6. 切分街区，按土地用途填充房子和树
  7. 处理水体和铁路
  8. 放置地标
  9. 按区块输出到 `public/maps/markham/`

### 6.3 渲染与性能
- 按区块（约 128 米）加载和卸载；加载半径随镜头拉远而扩大。
- 每个区块的静态几何合并成网格；重复物件（房子、树、路灯）用 InstancedMesh。
- 手机上 draw call 控制在约 150 以内。
- 阴影贴图 1024–2048，阴影相机跟随主角，移动时对齐纹素网格防止闪烁。
- 手机端像素比上限 1.5。

### 6.4 实体上限与回收
- 手机默认上限（可配置）：附近活跃路人 ≤ 40，车流 ≤ 20，警察 ≤ 8。
- 远离视野的实体回收复用。例外：正在追捕的警察、主角刚下的车不回收。

### 6.5 调试
URL 加 `?debug=1`，显示 FPS、draw call、实体数、物理体数、区块边界。

### 6.6 测试
- Vitest：地图管线变换、路人和警察的决策逻辑、战斗数值。
- Playwright 冒烟测试：
  - 检查页面能加载、控制台没有报错
  - 截两张图：手机横屏 844×390、桌面 1440×900
  - 无头浏览器用 SwiftShader 软件渲染来跑 WebGL

### 6.7 CI 与部署
- 每个 PR 自动跑 lint、test、build、e2e。
- 合并到 `main` 后 GitHub Actions 构建并发布到 GitHub Pages。Vite 的 `base` 设为仓库名。

### 6.8 网络
- 需要联网下载的东西（OSM 数据、Kenney 素材）在电脑本地阶段一次下完并提交进仓库。
- 以后如果在云端环境运行时连不上某个网站，直接告诉我地址，不要绕路下载。

## 7. 性能与体积预算
- 帧率：中端手机（iPhone 12 / Pixel 6 级别）≥ 30fps，电脑 60fps。
- 加载：首次下载量 < 15MB，4G 网络下 10 秒内能开始玩。
- 记录：每个里程碑结束时，用 debug 模式记录基准场景的帧率和 draw call，写进 PROGRESS。基准场景是 Hwy 7 × Kennedy 路口，实体满员。

## 8. 内容红线
- 暴力全部卡通化：不出血、不肢解、没有死亡，被打倒只冒星星、晕倒，然后爬起来。
- 不用真实品牌 logo 和商标名，用谐音恶搞名。真实路名、地名、政府机构名可以用。
- 游戏里任何地方不出现 “GTA” 或 “Grand Theft Auto”。
- 只用自己做的或 CC0 授权的素材，保留 OpenStreetMap 署名。

## 10. 工作方式
- **只做当前里程碑**。新想法写进 `docs/BACKLOG.md`。
- **调参**：手感相关的数值全部放 `src/config/`。
- **自己拿主意**：技术细节和小的设计取舍自己决定，记进 `docs/DECISIONS.md`。
- **问我**：只有影响玩法方向、范围、要花钱，或者红线拿不准时才问。问的时候直接给选项和你的推荐。
- **记录进度**：每完成一个任务就更新 `docs/PROGRESS.md`。
- **语言**：代码用英文命名和注释；文档和玩家看到的文字用中文，并维护英文翻译。
- **提交**：小步提交，提交信息写清楚做了什么。
