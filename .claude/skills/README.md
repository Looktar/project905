# Project skills

Claude Code loads these automatically when a task matches.

| Skill | Use it for |
|---|---|
| `game-feel` | impacts, screen shake, hit-stop, squash & stretch |
| `performance-optimization` | measure first, frame and asset budgets |
| `create-game-assets` | adding Polyfork / CC0 models: manifest, style target first, provenance |

These three skills are copied unchanged from
[gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)
(Apache-2.0, see `LICENSE-awesome-gamedev-agent-skills` and `NOTICE-awesome-gamedev-agent-skills`).
Their code examples are written for Godot and Unity. In this project, translate them to our own stack,
native WebGL2 with no engine (see `CLAUDE.md`).
